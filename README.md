# Ovalie Gestion — maquette

Maquette HTML interactive d'un outil de gestion pour association sportive (club de rugby fictif « RC Val d'Adret »).

**Toutes les données sont fictives et générées** (aucune donnée réelle). Les modifications faites dans la page vivent en mémoire et sont réinitialisées au rechargement.

## Modules

- **Licenciés** : liste filtrable, fiches, certificats médicaux, cotisations
- **Comptabilité** : synthèse, connecteur bancaire simulé (rapprochement), paiements en ligne simulés, journal
- **Stock multi-pôles** : sportif, pharmacie, administratif, buvette — seuils, péremptions, mouvements
- **Codir & AG** : préparation (ODJ, convocations), séance (émargement, quorum), votes, compte-rendu

## Utilisation

Ouvrir `index.html` dans un navigateur — aucun serveur ni installation nécessaire.
